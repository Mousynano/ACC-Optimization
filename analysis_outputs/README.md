# Analysis output index

Generated by `analysis_pipeline.py` from the frozen Framework V2.2-FJE campaign.

- `01_objective/`: all-run scalar cost, FJE physical components, representative controllers, gain-boundary audit.
- `02_convergence/`: median/IQR convergence across 30 runs per algorithm.
- `03_statistics/`: Q-Q, Shapiro-Wilk, Friedman, paired Wilcoxon with Holm and Bonferroni corrections.
- `04_motion/`: comparative trajectory motion for OpenACC calibration/validation, WLTC, periodic cruise, sinusoidal following.
- `05_safety/`: TTC time series and observed/operational TTE event tables.
- `06_time_response/`: rise, settling, overshoot, steady-state error for all ten cruise set-speed transitions.
- `07_robustness/`: inherited 12-case physical-parameter stress test.
- `08_audit/`: experiment consistency checks and analysis contract metadata.

TTC/TTE and robustness are validation evidence only; they do not modify the frozen optimization fitness.
